# Python Learning

This repository is dedicated to my journey of learning Python programming. It contains a collection of exercises, code snippets, and projects I am working on to reinforce my Python skills. The topics range from basic concepts to more advanced topics like object-oriented programming, working with APIs, and FastAPI.

## Technologies and Topics I'm Learning

I am currently focusing on the following Python concepts and libraries:

- **Basic Python Programming**: Syntax, data types, operators, and control flow.
- **Object-Oriented Programming (OOP)**: Classes, objects, inheritance, and polymorphism.
- **Data Structures**: Lists, dictionaries, sets, tuples, and other built-in data structures.
- **Functions and Modules**: Creating and using functions, understanding Python modules.
- **File Handling**: Reading and writing files in Python.
- **Python Libraries**: Working with libraries like `FastAPI`, `NumPy`, `pandas`, and others for various tasks.
- **Web Development with FastAPI**: Building APIs and understanding web frameworks.
- **Jupyter Notebooks**: Using Jupyter Notebooks for interactive coding and learning.
